# Time-Series Sensor Data Analysis with Python
This project analyzes time-series sensor data for trends, patterns, and differences over time. We cleaned the data, created visualizations, and used statistical tests to better understand changes in the sensor readings. The goal was to practice data analysis skills using real-world data in Python.

# Overview
- This project analyzes sensor data to find trends, patterns, and differences over time. We used Python to clean the data, create graphs, and run t-tests to check for significant changes in the data.


# Goals
- Clean and explore sensor data
- Find missing values and outliers
- Visualize sensor readings over time
- Run t-tests to compare time periods

# Tools Used
- Python
- Jupyter Notebook
- Pandas, Matplotlib, Seaborn, Scipy, Numpy

# Key Findings
- Some sensors had missing or unusual data
- Found differences between readings in different time periods
- Visualized data using graphs and rolling averages
